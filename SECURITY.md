# Security and integrity

Report vulnerabilities in the benchmark infrastructure, ways to obtain hidden-split answers, grading exploits, or any
generated content that resembles a real person closely enough to cause harm to contact@durandir.com rather than in
a public issue. Reports are acknowledged within five working days.

The world gateway is designed for evaluation, not as a security boundary for untrusted code: run third-party
harnesses in their own containers with no other network access than the gateway and their model provider.
